# Smart Storyboard AI - Android project (Phase 1 prototype)
Option A (no PC): create a GitHub repo, upload all these files, open Actions > Build APK > Run workflow,
download the APK artifact, copy to phone, allow "install unknown apps", install.
Option B: open this folder in Android Studio (Koala+), press Run with your phone in USB debugging mode.
UI lives in app/src/main/assets/index.html (sample data only).
